# Social card fonts

Static TTF instances used by the link preview and feed post images (`src/lib/seo/social-card`).
Satori, behind `next/og`, cannot read woff2, so these are the Google Fonts TrueType files of the
same faces the site loads through `next/font`:

- Bricolage Grotesque 700, 800 (opsz 96) — SIL Open Font License 1.1
- Geist 400, 500, 600 — SIL Open Font License 1.1
- Geist Mono 500 — SIL Open Font License 1.1
